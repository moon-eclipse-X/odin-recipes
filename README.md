# 🍳 odin-recipes

Hello! 👋  
Welcome to my very first published website. On this site, I showcase a collection of delicious recipes written in Dutch.

Right now, the project is built using **pure HTML**, but I will be adding **CSS** later to style it and make it look amazing!

---

## 📖 Featured Recipes

I have included four of my favorite recipes:

* **Caprese brood** (Caprese bread) — A delicious Italian-style sandwich.
* **Lasagna** (Lasagne) — A classic, hearty pasta bake.
* **Linguine** (Linguine) — Long, flat pasta strands perfect for rich sauces.
* **Bananenpannenkoeken** (Banana pancakes) — A sweet and simple breakfast favorite.
